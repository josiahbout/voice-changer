# Driver source

Empty until you run `..\scripts\fetch-driver-source.ps1`, which downloads
[JannesP/AudioMirror](https://github.com/JannesP/AudioMirror) (MIT) at commit
`a9618d1ab4114e3e35e8e50ae804a4205315d1f2` into this folder.

Keep upstream's `LICENSE.md` alongside the code; MIT requires it to ship with any copy.
AudioMirror is derived from Microsoft's SysVAD sample (MS-PL), so carry that notice too
when we distribute it.
